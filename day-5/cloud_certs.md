# Cloud certification guidance
Of the big three cloud providers, it only recommended to get certifications for one. The skills are mostly transferable.

I would also recommend paying for a training course (on Udemy or similar) as although you know much of what you need, small details like names of services, certain scenarios etc. needs to be learned in a more traditional way before you attempt the exam.

## AWS

* [Certified Cloud Practitioner](https://aws.amazon.com/certification/certified-cloud-practitioner/)
  * Cost = $100 (£80 est)
  * Level = Intermediate

## GCP
* [Google Associate Cloud Engineer](https://cloud.google.com/learn/certification/cloud-engineer)
  * Cost = $125 (£100 est)
  * Level = Intermediate

## Azure
* [AZ-900 (Azure Fundamentals)](https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/?practice-assessment-type=certification)
  * Cost = $99 (£80 est)
  * Level = Beginner

* [Specialisation after AZ-900 (Associate/Intermediate level)](https://k21academy.com/azure-cloud/azure-certification-path-2025-roadmap/)


## Terraform
* [Hashicorp Certified: Terraform Associate (003)](https://developer.hashicorp.com/certifications/infrastructure-automation)

  * Cost = $70
  * Level = Beginner
