# Deploy Application
1. Connect to the app
    ```
    ssh -i "se-dare-key-pair.pem" root@54.247.226.54
    ```
2. Check files and directory.
    ```
    ls
    ```
3. Enter the directory with the application script
    ```
    cd nodejs2-sparta-test-app-2025/app
    ```
4. Install npm
    ```
    sudo npm install --yes
    ```
5. Confirm package manager installed
    ```
    pm2 --version
    ```
6. Kill any active operations
    ```
    pm2 kill
    ```
7. Start app
    ```
    pm2 start app.js
    ```
8. Using the public IPv4 address, check that the app is running (ensure on http and not https)

# Issues Raised
## SSH Error: Unprotected Private Key File
SSHE requires private key files to be restricted to the owner only, to prevent credential compromise.
Permissions 0644 are too open, meaning other users can read the key.
* Private keys must have permissions `400` or `600`.
* Resolved by running: `chmod 400 se-dare-key-pair.pem`

Review [Chmod Calculator](https://chmod-calculator.com/) for more information.

![Error message: Unprotected Private Key](../images/error-unprotected_private_key.png)

## EC2 Login Error: Use `ubuntu` instead of `root`
On Ubuntu-based EC2 instances, direct root login is disabled by default for security reasons.
* The default SSH user is `ubuntu`
* The ubuntu user has sudo privileges

Resolved by logging in using `ubuntu` instead of `root`.

![Error message: Root User](../images/error-root-user.png)
