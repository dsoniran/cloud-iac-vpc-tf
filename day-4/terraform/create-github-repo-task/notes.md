# Notes on getting Personal Access Token (PAT) for GitHub

1. Go to your GitHub account

2. Click on Settings -> Developer settings -> Personal access tokens -> Fine-grained token -> Generate new token

3. Enter **Token name**

4. Enter **Expiration** period

5. For Repository access, select **All repositories**

6. For Permissions, select **Adminsitration**

7. For **Administration**, select **Read and write**

8. Select **Generate Token**
